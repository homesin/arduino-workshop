ThingSpeak 的 Write API Key、ntfy 的主題名稱，等同密碼：不要貼在群組、不要截圖給別人、不要貼給 AI。ntfy 的主題名稱要自己取、要夠難猜，全班不能共用同一個。

Arduino 套件是借用的

Uno、四個感測器、麵包板和杜邦線是學校的，借你使用，不是送的。

  • 上課時：現場發給你，兩人一組共用一套。
  • 下課後：不繼續借就當場歸還；想借回去複習，要填借用單（姓名、電話），一個月內歸還。歸還地點與聯絡方式，請看現場說明。

沒有板子的時候，軟體部分（npm run mock 模擬模式、ThingSpeak、ntfy）一樣可以在自己的電腦練習。
