一行指令安裝（建議）

上課前在自己的 Windows 電腦做一次，約 15–30 分鐘（視網路速度）。軟體全部自動安裝，最後會列出檢查結果。

用相容板的話，建議先裝 CH340 驅動（板子上的 USB 晶片是 CH340／CH341，沒裝電腦認不得板子；原廠 Uno 可跳過）。安裝指令也會自動裝，但學校電腦常擋住，先手動裝比較保險：

下載 CH340 驅動（CH341SER.EXE） 或到 WCH 官網下載頁。下載後執行，按「安裝」，出現「驅動安裝成功」即可。

  1. 開啟 PowerShell 按鍵盤的 ⊞ Win 鍵，輸入 PowerShell，按 Enter。不需要「以系統管理員身分執行」。
  2. 複製下面的指令，貼到 PowerShell，按 Enter

  3. 跳出確認視窗時按「是」 安裝 CH340 驅動和部分軟體時，Windows 會問「是否允許此應用程式變更您的裝置」。按「否」會讓該項目失敗。
  4. 看最後的結果表 出現綠字「全部完成，這台電腦可以上課了」就完成了。教材會放在桌面的 arduino-workshop 資料夾。

    ✓ 成功　！ 不影響上課，但請看說明　✗ 失敗，修好後重新執行即可（已裝好的會自動跳過）

手動下載（指令無法執行時）

下載教材 zip（97 KB）

  1. 解壓縮對 zip 檔按右鍵 →「解壓縮全部」，建議放在桌面。
  2. 雙擊 安裝程式\install.cmd 若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。只裝 Arduino 的話，在該資料夾開啟終端機執行 .\install.cmd -ArduinoOnly。

個別安裝：分別下載

一鍵安裝失敗，或只缺其中一樣時用。板子核心（Arduino AVR Boards）與 SimpleDHT 函式庫不用另外下載，在 Arduino IDE 的「開發板管理員」與「函式庫管理員」裡安裝。

軟體用途下載連結
Arduino IDE寫程式、按上傳arduino.cc/en/software
CH340 驅動相容板的 USB 驅動wch-ic.com 下載頁
Node.js（選 LTS 版）第六章送資料上雲端nodejs.org/en/download
VS Code（選用）另一種編輯器code.visualstudio.com/download

常見問題

貼上指令後出現紅字錯誤
可能是學校網路或電腦政策擋住了，改用上面的「手動下載」。
公務電腦、電腦教室沒有安裝權限
請先請資訊人員協助，或在確認視窗輸入管理員帳號密碼。
結果表的「偵測到板子」是 ！
沒有插板子時一定會這樣。把 Uno 用 USB 線接上電腦後，雙擊桌面 arduino-workshop\安裝程式\install.cmd 再檢查一次。若仍偵測不到，換一條 USB 線（有些線只能充電）。
「Codex 登入」是 ！
第一次使用要登入：在 arduino-workshop 資料夾開終端機輸入 codex，用 ChatGPT 帳號登入。上課時再做也可以。
重新執行會蓋掉我改過的程式嗎？
不會。桌面已有 arduino-workshop 時，只會更新安裝腳本、補上缺少的檔案。
