# 115.11.14 Arduino 實作研習

學員電腦安裝請看：**https://homesin.github.io/arduino-workshop/**

或直接在 PowerShell 貼上：

```powershell
irm https://homesin.github.io/arduino-workshop/get.ps1 | iex
```

| 資料夾 | 內容 |
|---|---|
| `範例程式/` | 第三到五章用的 7 支 Arduino 程式與接線圖 |
| `雲端實作/` | 雲端單元的 Node.js 專案（感測資料上網、ntfy 手機通知） |
| `安裝程式/` | 一鍵安裝＋驗收腳本，雙擊 `install.cmd` |
| `學員講義.html` | 上課跟做的講義 |

這個 repo 由講師端的 `deploy.ps1 -GitHub` 自動產生，請不要直接修改。
