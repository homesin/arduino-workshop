# 範例程式

本次課程第三至五章用的 Arduino 程式。腳位全部一致，學員從個別感測器走到整合版**不用重接線**。

| 資料夾 | 章 | 做什麼 | 接線 |
|---|---|---|---|
| `c03a-blink` | 三 | 板上內建 L 燈閃爍（第一次上傳） | 不用接 |
| `c03b-serial-hello` | 三 | 序列埠：讓板子說話、變數、`if` | 不用接 |
| `c04a-dht11` | 四 | 溫濕度，處理讀取失敗 | DATA→D2 |
| `c04b-hcsr04` | 四 | 超音波測距，自己換算公分 | Trig→D4、Echo→D5 |
| `c04c-pir` | 四 | 人體紅外線，暖機與邊緣觸發 | OUT→D3 |
| `c04d-ldr` | 四 | LM393 光敏，類比輸入與門檻 | AO→A1（DO 不接） |
| `c05-sensor-node` | 五 | 四個一起讀，不用 `delay`，每秒一行 JSON | 同上全部 |

所有感測器的 VCC→5V、GND→GND（共用麵包板電源軌，見 `接線圖/wiring-5-bought-power.svg`）。

## 需要的函式庫

只有 **SimpleDHT**（作者 Winlin），給 `c04a-dht11` 和 `c05-sensor-node` 用。其他程式不需要。

## 每支程式的共同結構

檔頭註解固定寫：**目標、接線、原理**；檔尾註解固定寫：**動手試試、常見狀況**。
對應簡報第四章「七步版型」：量什麼 → 怎麼運作 → 接哪幾支腳 → 程式 → 讀到什麼數字 → 數字代表決定 → 常見錯誤。

| 項目 | 結果 |
|---|---|
| 7 支全部編譯 | 通過 |
| 7 支全部上傳 | 通過 |
| `c03b`、`c04a`、`c04d`、`c05` 序列埠輸出 | 實際讀到，中文與 JSON 格式正確 |
| `c04b` 超音波、`c04c` PIR | 這兩支單獨程式今天沒有目標物／沒人揮手，**沒有逐支驗證到「有讀數」**。講師表示昨天（2026-10-30）現場測試四個感測器都 OK，**視為通過**；接線與腳位和整合版完全相同 |

昨天的整合測試：四個欄位（溫濕度、人體、距離、光線）都會隨環境變化，序列埠與 Node.js 儀表板都收得到。

## 要注意的數字（只是範例，要現場量）

- 光敏 LM393 是**越暗越大**。同一個模組，白天約 280、遮住約 490，傍晚室內可以到 650 以上，所以 `c04d` 的 `DARK_THRESHOLD = 400` 不能照抄。
- DHT11 的 `TOO_HOT = 32`、超音波的 `NEAR_CM = 30` 也都是範例值。

## 與封存快照的關係
