課後練習：四個延伸題

沿用上課寫好的雲端程式，改幾行就能做出新功能。四題由簡單到進階，題 1、2 不用板子（模擬模式就能驗證）。

練習題
  1. 天暗自動通報
  2. 兩個條件一起判斷
  3. 加上 LINE 通知
  4. 分享你的圖表
開始之前：四題都要先完成上課的雲端實作（雲端實作啟動），也就是 雲端實作 資料夾裡的 npm run mock 跑得起來。 改程式用 VS Code（VS Code 教學），先用 File → Open Folder 開啟桌面的 arduino-workshop 資料夾。下面的路徑都從這個資料夾算起。改壞了不用怕：把 src\index.js 裡你新增的那幾行刪掉就回到原樣。

1天暗自動通報

上課的程式只會在「有東西靠近」和「有人經過」時通知。照同樣的寫法，再加一條：光線太暗就通知。光敏模組的數字越大越暗。

  1. 用 VS Code 開啟程式檔 桌面\arduino-workshop\雲端實作\src\index.js（左邊 Explorer 依序點 雲端實作 → src → index.js），找到這一行：
      if (reading.pir === 1) {
  2. 在它的上面貼上這一段： 
      // 練習 1：天暗通報（light 越大越暗；400 只是範例，要換成你量到的值）
  if (reading.light > 400) {
    await fireAlert('dark', `🌙 天暗了\n光線 ${reading.light}（門檻 400）\n時間 ${stamp()}`);
  }
  3. 存檔（Ctrl + S），終端機進到 雲端實作，先停掉舊的（Ctrl + C），再執行：
    npm run mock
模擬模式的光線只在 280～300 之間跳：門檻 400 永遠不會觸發。要看到效果，先把 400 暫時改成 290，終端機就會每隔幾秒印出「天暗了」。確認有效後再改回自己量到的值。
真實的門檻怎麼訂：接上板子，跑 npm start，看儀表板上「光線」：平常的數字、用手遮住的數字，取中間值（簡報第四章光敏那一組有算法）。
為什麼不會一直響：同一種警報有冷卻時間（.env 的 ALERT_COOLDOWN_SEC，預設 60 秒），一分鐘內不會重複通知。
檢查點：終端機出現 [LINE 預演] 若已設定憑證，會送出：🌙 天暗了（已填 ntfy 主題的話，手機也會收到）。「LINE 預演」是程式在說：沒有設定 LINE，所以只印出來、沒有真的送。

2兩個條件一起判斷

只要「有人經過」就通知，白天也會響。改成天暗而且有人才通知：用 &&（而且）把兩個條件接起來。

  1. 在 src\index.js 練習 1 的下面（if (reading.pir === 1) { 的上面）再貼一段： 
      // 練習 2：天暗而且有人，才通知
  if (reading.pir === 1 && reading.light > 400) {
    await fireAlert('night-pir', `🌙🚶 天暗了還有人\n光線 ${reading.light}\n時間 ${stamp()}`);
  }
  2. 一樣把 400 暫時改成 290，執行 npm run mock。模擬資料大約每 25 秒有一次「有人」，等一下就會看到。
想只留這一條：把原本的 if (reading.pir === 1) {…} 整段刪掉或前面加 // 變成註解，這樣白天有人經過就不會通知了。
檢查點：印出「天暗了還有人」；沒有「有人」的那幾秒，只有練習 1 的「天暗了」。

3加上 LINE 通知

程式已經寫好 LINE 通知，只差帳號和設定。這一題要自己申請 LINE 官方帳號，大約 15 分鐘。

  1. 到 developers.line.biz，用 LINE 帳號登入，建立一個 Messaging API channel（會一併建立 LINE 官方帳號）。
  2. 進入該 channel 的 Messaging API 分頁，最下面 Channel access token (long-lived) 按 Issue，複製那一長串。
  3. 用手機掃同一頁的 QR Code，把自己的官方帳號加為好友（沒加好友就收不到）。
  4. 用 VS Code 開啟設定檔 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env），加上這一行（貼上你的 token）：
    LINE_CHANNEL_ACCESS_TOKEN=貼上你的token
  5. 找到 NOTIFY_CHANNELS=ntfy 這一行，改成：
    NOTIFY_CHANNELS=ntfy,line
    這行是「只送哪幾家」的過濾器，不改的話 LINE 會被擋掉，什麼都收不到。
  6. 存檔，終端機執行 npm run mock，等一則警報，手機 LINE 就會收到。
額度要看清楚：免費的「輕用量」方案每月 200 則，而且群發給 N 個好友會扣 N 則。所以請用自己申請的帳號、只加自己一個人好友；也不要一直重啟測試。程式內建每天最多送 20 則的保險（LINE_DAILY_LIMIT）。
Token 等同密碼：不要貼在群組、不要截圖、不要貼給 AI。LINE 官網的畫面與按鈕名稱可能改版，以官網現況為準。
不需要架 webhook：這裡只是往外「送」通知，不需要對外開放任何網址。要做「你傳訊息、機器人回覆」的問答機器人才需要 webhook，那是更進階的題目，這次不涵蓋。
網路上教學寫的 LINE Notify 已經停止服務（2025-03-31）。看到「LINE Notify 權杖」的教學都不要照做，要用本頁的 Messaging API。
檢查點：終端機開場橫幅有一行「警報通知　✔ 已啟用　LINE」；警報出現時終端機寫「LINE 已送出：…」，手機 LINE 收到訊息。

4分享你的圖表

把上課做的 ThingSpeak 圖表，變成一個網址，傳給朋友就能看，對方不用註冊、不用登入。

  1. 照 ThingSpeak 看圖表與分享 · 步驟 4「公開檢視與分享網址」 把頻道設成公開（Sharing 分頁 → Share channel view with everyone）。
  2. 複製頻道的公開網址，傳給朋友。
  3. 確認資料有持續進來：板子或 npm run mock 要一直開著，圖表才會更新。
別人只能看，不能亂寫：公開的只是「看圖表」的權限，要往頻道寫資料一定要有 Write API Key。所以Write API Key 不要一起傳出去，只傳網址。
免費版的限制：每 15 秒最多一筆、每年 300 萬則、僅限非商用。
檢查點：用手機（沒登入 ThingSpeak 的瀏覽器）打開網址，看得到圖表。
