Slack 通知教學

從建立工作空間、建立 App，到讓 Arduino 的警報傳到 Slack 頻道。免費，約 20 分鐘。

步驟
  1. 先搞清楚：Slack 通知怎麼運作
  2. 註冊並建立工作空間
  3. 建立 Slack App
  4. 複製 Webhook 網址
  5. 填進 .env
  6. 送一則測試通知
  7. 常見問題

1先搞清楚：Slack 通知怎麼運作

Slack 的做法是：建一個 Slack App，替它開一個「Incoming Webhook」，Slack 會給你一個專屬網址，程式把訊息 POST 到這個網址，訊息就會出現在你指定的頻道。要準備的是：一個 Slack 工作空間、一個 App、一個 Webhook 網址。

什麼時候選 Slack：學校或團隊本來就在用 Slack，通知直接進工作頻道，不必另外裝 App。只是自己收通知的話，Telegram、Discord 步驟比較少。
全程不要付費：Slack 建好工作空間時會跳出付費方案（Business+）的推銷畫面。本教學只用免費功能，不需要按「開始免費試用」或「結帳」（步驟 2 有說明怎麼關掉）。

2註冊並建立工作空間

開啟 Slack 註冊頁
  1. 登入或註冊：輸入 email，或用 Google、Microsoft 登入。驗證碼請自己輸入。
  2. 同意條款：建立新工作空間前，會要你同意服務協議與使用者條款，請自己看過再按「繼續使用新的工作空間」。
  3. 為工作空間命名：取個名字，例如 Arduino 通知測試。
  4. 你的名稱：預設會帶入你 email 的前半段，直接按「下一步」就行。
  5. 邀請團隊成員：只有自己用，按「略過此步驟」，再在確認視窗按「不邀請任何人」，不會寄出邀請信。
  6. 歡迎問卷：「你想怎麼用 Slack？」隨便選一項（例如「其他」），只影響畫面建議。
  7. 付費方案推銷：接著會出現「開始使用 Business+」的畫面，只有「取得優惠並結帳」和「開始免費試用 30 天」兩個按鈕，都不要按，直接按鍵盤的 Esc 關掉。
Slack 的新手引導常改版，畫面順序可能不同，原則是：不邀請人、不付費、能略過的略過。

3建立 Slack App

開啟 Slack API 的 Your Apps
  1. 用剛才的帳號登入，按「Create an App」。
  2. 在「Create new app」視窗，找到「From scratch」區，選「Pick features」，按 Continue。
  3. App 名稱用英數字，例如 Arduino Notify；Workspace 選你剛建的工作空間，按 Continue。
  4. 權限（Scopes）：在搜尋框輸入 incoming-webhook，點出現的 Bot scope 加入。說明是「Post messages to specific channels in Slack」，只能往頻道發訊息，不能讀訊息。
  5. 事件（Events）：這一步不用選，直接 Continue。
  6. 檢查：最後一步 Review，看到 What it can do 是 1 項，按「Create and Install」。
  7. 授權：Slack 會把這個 App 安裝進你的工作空間，並要你選一個頻道、按「允許」。這是在授權「這個 App 可以往該頻道發訊息」，請自己按。
  8. 完成後出現「Arduino Notify is ready!」，按「Go to App Settings」。

4複製 Webhook 網址

  1. 在 App Settings 左側選單往下找「Incoming Webhooks」（在 Features 區，要往下捲）。
  2. 往下捲到「Webhook URL」表格，會看到一筆已經建好的 Webhook，頻道就是你剛才授權時選的那個。按那一列的「Copy」，網址就複製到剪貼簿了。
Webhook 網址等於密碼：知道的人都能往你的頻道發訊息。不要貼在群組、截圖、簡報或公開網站，這頁的 curl 範例也含完整網址，截圖要一起遮。
外洩了就在同一個表格按右邊的垃圾桶刪除，再按「Add New Webhook」重建。
如果沒有看到任何 Webhook：確認上方「Activate Incoming Webhooks」開關是 On，再按「Add New Webhook」，選頻道、按允許。

5填進 .env

用 VS Code 開 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env）：

  1. 找到 NOTIFY_CHANNELS= 那一行，加上 slack（用逗號分隔，可以同時開好幾種）：
    NOTIFY_CHANNELS=ntfy,slack
    這行是「只送哪幾家」的過濾器，不加的話 Slack 會被擋掉，什麼都收不到。
  2. 在下面加一行，貼上剛才複製的網址：
    SLACK_WEBHOOK_URL=貼上網址
  3. 存檔。
等號兩邊不要有空格，也不要加引號。

6送一則測試通知

在 VS Code 終端機（路徑要在 雲端實作 資料夾裡）執行：

node test/send-test-alert.js slack

只送給 Slack，不影響其他管道。成功的話終端機會顯示：

Slack 已送出：測試警報 · 校園環境監測站
✔ Slack 送出成功

同時 Slack 的頻道（網頁、手機都看得到）會多一則由你的 App 傳來的訊息：

檢查點：終端機顯示成功，而且頻道裡真的出現那則訊息，才算完成。
要在手機跳通知：手機裝 Slack App、登入同一個工作空間，並允許通知。要看感測器真的觸發警報，接上 Arduino 後執行 npm start；沒有板子可用 npm run mock。

7常見問題

狀況原因與做法
錯誤 404（no_service、no_team）網址貼錯、少貼一段，或那個 Webhook 已被刪除、App 已被移除。回步驟 4 重新複製。
終端機說沒有任何通道被啟用NOTIFY_CHANNELS 沒加 slack，或 SLACK_WEBHOOK_URL 沒填。
程式說成功，但頻道沒看到訊息確認看的是建 Webhook 時選的那個頻道，不是別的頻道或別的工作空間。
找不到 Incoming Webhooks 選單App Settings 左側選單很長，要往下捲；或直接在網址列把結尾改成 /incoming-webhooks。
一直被導去付費畫面用 Esc 關掉；不要按「開始免費試用」或「結帳」。
校園網路連不上學校網路可能擋 Slack。先換手機熱點試試，確認是不是網路的問題。
Slack 的畫面與新手引導常改版，步驟以你實際看到的為準；官方說明見 Incoming Webhooks。
