Telegram 通知教學

從註冊帳號、建立機器人，到讓 Arduino 的警報傳到你的 Telegram。免費，約 15 分鐘。

步驟
  1. 註冊並登入 Telegram
  2. 找到 BotFather
  3. 建立機器人：/newbot
  4. 複製 Token（機器人的密碼）
  5. 對你的機器人說一句話
  6. 取得你的 Chat ID
  7. 填進 .env
  8. 送一則測試通知
  9. 常見問題

1註冊並登入 Telegram

Telegram 是免費的通訊軟體，建機器人要先有帳號。手機和電腦網頁版都可以，擇一即可：

開啟 Telegram 網頁版 下載手機 App
  1. 已經有手機 App：網頁版選「Log in by QR Code」，手機 App 進「設定 → 裝置 → 連結桌面裝置」，掃螢幕上的 QR Code，不需要簡訊。
  2. 用手機號碼：按「Log in by phone number」，國碼選台灣 +886，後面輸入 9 開頭的 9 碼，不要加開頭的 0（例如 0912345678 要輸入 912345678）。
  3. 驗證碼會傳到你手機上的 Telegram App（來自官方的「Telegram」對話），沒有 App 才用簡訊。
收不到驗證碼：先等倒數結束，再點「Send code via SMS」或「Call me」（語音電話念給你聽）。不要一直重新整理或重按，連續失敗會被限制幾小時。最快的辦法是改用手機 App 掃 QR Code。
重新輸入電話號碼：網頁版記住了舊號碼的話，登入畫面按「Change phone number」，或用無痕視窗開啟網頁版。

2找到 BotFather

BotFather 是 Telegram 官方用來建機器人的帳號。搜尋 BotFather，點名字旁邊有藍色勾勾、帳號是 @BotFather 的那一個。

直接開啟 BotFather
小心假帳號：搜尋結果裡有名字很像、但沒有藍勾的帳號，不要點。

進入對話後按下方的 START，BotFather 會列出所有指令。

3建立機器人：/newbot

  1. 在對話框輸入 /newbot 送出。
  2. BotFather 問名字（Please choose a name for your bot）：輸入顯示名稱，隨意取，例如 Arduino Notify Demo。
  3. 接著問使用者名稱（choose a username）：要英文、數字、底線，結尾必須是 bot，而且不能和全世界別人重複，例如 ncyu_arduino_你的代號_bot。被用掉了它會請你換一個。

4複製 Token（機器人的密碼）

BotFather 回覆「Done! Congratulations on your new bot」的訊息裡，有一行橘色、像 123456789:ABCdef... 的字串，那就是 Token。點一下就會複製。

Token 等於機器人的密碼：拿到的人可以控制你的機器人、用它發訊息。不要貼在群組、截圖、簡報或公開網站。
不小心外洩了：到 BotFather 輸入 /revoke，選你的機器人，會產生新的 Token，舊的立刻失效。

5對你的機器人說一句話

機器人不能主動傳訊息給陌生人，你要先跟它說過話，它才有辦法傳給你，也才拿得到你的 Chat ID。

  1. 點 BotFather 訊息裡的 t.me/你的機器人名稱 連結（或在搜尋輸入機器人的使用者名稱）。
  2. 按下方 START，再隨便傳一個字，例如 hi。

6取得你的 Chat ID

Chat ID 是 Telegram 用來認「要傳給誰」的數字。用瀏覽器開下面的網址（把 <你的Token> 換成步驟 4 的 Token，連同前面的 bot 字樣，中間沒有空格）：

https://api.telegram.org/bot<你的Token>/getUpdates

畫面會出現一大串文字，找 "chat":{"id": 後面的數字，那就是 Chat ID：

{"ok":true,"result":[{"update_id":1,
  "message":{"message_id":2,
    "from":{"id":123456789,"first_name":"..."},
    "chat":{"id":123456789,"type":"private"},
    "text":"hi"}}]}
上面是示範：你的數字會不一樣，個人聊天的 Chat ID 通常等於你的使用者 ID。
"result":[] 是空的？代表機器人還沒收到訊息。回到步驟 5，再傳一句新的話（例如 ping），等幾秒，重新整理這個網址。
這個網址含有 Token：只在自己的瀏覽器開，不要分享網址或截圖。

7填進 .env

用 VS Code 開 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env）：

  1. 找到 NOTIFY_CHANNELS=ntfy 這一行，改成：
    NOTIFY_CHANNELS=ntfy,telegram
    這行是「只送哪幾家」的過濾器，不改的話 Telegram 會被擋掉，什麼都收不到。
  2. 在下面加上兩行（貼上你自己的）：
    TELEGRAM_BOT_TOKEN=貼上Token
TELEGRAM_CHAT_ID=貼上數字
  3. 存檔。
等號兩邊不要有空格，也不要加引號。

8送一則測試通知

在 VS Code 終端機（路徑要在 雲端實作 資料夾裡）執行：

node test/send-test-alert.js telegram

只送給 Telegram，不影響其他管道。成功的話終端機會顯示：

Telegram 已送出：測試警報 · 校園環境監測站
✔ Telegram 送出成功

同時手機（或網頁版）的機器人對話裡，會收到一則通知：

檢查點：終端機顯示成功，而且對話裡真的出現那則訊息，才算完成。
要實際看感測器觸發通知：接上 Arduino 後執行 npm start；沒有板子可用 npm run mock。測試腳本不需要啟動整套服務。

9常見問題

狀況原因與做法
收不到登入驗證碼先看手機 Telegram App 裡官方「Telegram」對話；改用 QR Code 登入；倒數結束後選「Call me」。
使用者名稱被拒絕要以 bot 結尾、只能英數與底線，且不能重複；加上自己的代號再試。
錯誤 401Token 貼錯或多了空格；或已經被 /revoke。回 BotFather 重新取得。
錯誤 400Chat ID 錯了，或你還沒對這個機器人說過話（回步驟 5、6）。
程式說送出成功，但沒看到訊息確認打開的是你自己的機器人對話，不是 BotFather；手機的 Telegram 通知權限有沒有開。
終端機說沒有任何通道被啟用NOTIFY_CHANNELS 沒加 telegram，或 Token 和 Chat ID 沒填齊（兩個都要）。
校園網路連不上學校網路可能擋 Telegram。先換手機熱點試試，確認是不是網路的問題。
