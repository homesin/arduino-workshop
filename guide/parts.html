想自己買？元件採購指南

課堂用的七樣東西各買什麼規格、大約多少錢、搜尋要打什麼字、最常買錯的地方；還有課程以外想玩的元件，以及怎麼請 AI 幫你寫程式測試。

先說明：這頁只講「買什麼」，不推薦特定賣家，也沒有商品連結（商品頁常會下架或改價）。價位是 2026 年 10 月的大約範圍，各賣家和時間會不同，請當成預算參考。

4最常買錯的地方

買錯會怎樣怎麼避免
DHT11 買成 DHT22（或 DHT21）外觀像，但程式不同，課程範例讀不到型號要寫 DHT11
買到沒有模組板的裸元件（4 腳、沒有電路板）需要另外接電阻，超出課程範圍找「模組」「帶板」「3 腳」
光敏模組沒有 AO 腳只能讀「亮／暗」兩種，課程要讀 0～1023 的數字商品圖看有沒有 AO 這個印字
麵包板買成 830 孔可以用，但體積大，課堂的接線圖也對不上位置認 400 孔
杜邦線買成母對母模組的針腳插得進去，但另一頭接不到麵包板要買母對公；Uno 接電源軌另買公對公
Uno 買成 Mega 或 Nano腳位和接法不同，範例不能直接上傳板名要寫 Uno R3

5課程以外還可以買什麼（延伸元件）

下面這些課堂沒有用到，但都是 Arduino Uno 能直接玩的入門元件，想延伸時可以自己挑。價位是我估的大約範圍，各賣家差很多，只供預算參考。

元件可以做什麼大約價位要注意
LED（5 mm）＋電阻 220～330 Ω天暗自動亮燈、有人靠近亮燈，是最直接的「執行」各約 30～100 元（一包）LED 一定要串電阻，否則會燒掉 LED 或腳位
蜂鳴器（主動式）距離太近就嗶嗶響約 15～50 元買「主動式」最簡單，通電就響；被動式要用程式產生頻率
按鈕、旋鈕（可變電阻）手動切換模式、調門檻值約 10～50 元按鈕要處理彈跳，請 AI 用內建上拉寫法
伺服馬達 SG90感測到東西就轉到某個角度約 60～120 元馬達吃電流，不要只靠 Uno 的 5V 供多顆；Servo 函式庫會占用 D9、D10 的 PWM
OLED 0.96 吋（I2C，SSD1306）在板子上直接顯示溫度、距離，不用接電腦約 120～250 元I2C 用 A4（SDA）、A5（SCL）；要裝顯示函式庫
LCD1602（I2C 版）同上，顯示兩行文字約 100～200 元買有 I2C 背板的，腳位少很多
即時時鐘 DS3231記錄「幾點幾分」發生什麼事約 60～150 元I2C，和 OLED 可以共用 A4、A5
土壤濕度、水位、火焰、氣體（MQ 系列）感測模組澆水提醒、積水通報、安全監測各約 30～150 元MQ 系列需要預熱，讀值是相對值；不能當成安全警報器
紅外線遙控器組、RFID（RC522）遙控切換、刷卡通報各約 40～120 元RC522 是 3.3V 元件，接錯會燒，請看商品頁的接線
步進馬達 28BYJ-48＋ULN2003 驅動板轉到指定圈數約 80～150 元要用驅動板，不能直接接 Uno 腳位
ESP32 開發板自己連 Wi-Fi，不用接電腦就能把資料送到 ThingSpeak 或 ntfy約 200～350 元邏輯電壓是 3.3V：HC-SR04 的 Echo 是 5V，要分壓；程式要請 AI 改成 ESP32 版
830 孔麵包板、公對母杜邦線、跳線組元件變多後比較好排各約 50～120 元——
安全：不要用繼電器去控制家用 110V／220V 市電，也不要接大電流馬達直接插 Uno。課程範圍內都是 5V 小訊號，延伸時請維持在這個範圍；需要控制電器的專題，請找有電力經驗的人協助。

6買回來，請 AI 幫你寫程式測試

課堂的 VS Code 裡有 AI 助教（Codex），其他 AI 也可以。AI 寫得對不對，關鍵是你給它的資訊夠不夠。把下面這段貼過去，再把【】換成你的內容：

我有一塊 Arduino Uno R3，已經接了這些東西（腳位不要動）：
DHT11→D2、HC-SR501→D3、HC-SR04 Trig→D4／Echo→D5、LM393 AO→A1，
VCC 接麵包板紅軌（5V）、GND 接藍軌。
我新買了【元件名稱與型號】，想做到【你想要的行為】。
請幫我：
1. 告訴我這個元件要接 Uno 的哪幾支腳（避開上面用掉的腳位和 D0、D1）。
2. 寫一支可以直接上傳的 .ino，用 9600 baud 在序列埠印出讀值。
3. 說明需要安裝哪個函式庫、怎麼安裝。
4. 列出接線前要注意的電壓或電流限制。
寫程式前先知道說明
Uno 已用掉的腳位D2、D3、D4、D5、A1；D0、D1 留給序列埠，不要接
還能用的腳位D6～D13、A0、A2、A3；A4、A5 是 I2C（OLED、LCD、時鐘共用）
PWM 腳位D3、D5、D6、D9、D10、D11
互相打架的情況tone() 會讓 D3、D11 的 PWM 失效；Servo 會讓 D9、D10 的 PWM 失效
先確認，再上傳：AI 說的腳位，請你先拔掉 USB、對照商品頁的腳位印字再接線，接好檢查一遍再上傳。AI 常會把腳位或電壓記錯，上傳前多看一眼不會吃虧。
程式出錯時：把完整的錯誤訊息（編譯錯誤或序列埠的輸出）貼給 AI，並說明你的接線，通常一兩輪就能改好。卡在課堂已經教過的部分，可以回到 排錯與驗收總表。
想把新感測器的數字也送到儀表板：課程的 Node.js 讀的是一行 JSON，欄位名稱固定。請 AI「保留原本 c05 的欄位、只多加一個欄位」，並先自己在序列埠確認格式沒壞，再接上 Node.js。

7買回來之後

  1. 用 一鍵安裝與驗收 把軟體裝好。
  2. 照 Arduino 第一次上傳與序列埠 上傳第一支程式，確認板子能動。
  3. 用 麵包板與四感測器接線 一個一個接，每接好一個就看數字。
  4. 想再往下做，看 課後練習：四個延伸題都不需要多買零件。
不要照抄別人的金鑰：ThingSpeak 的 Write API Key 和 ntfy 的主題名稱要自己建立，不要用課堂範例或別人貼出來的。
