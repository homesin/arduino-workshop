Arduino 第一次上傳與序列埠

讓板子上的燈閃起來，再讓板子「說話」。不用接任何線，只要一條 USB 線。

步驟
  1. 接上板子、打開範例
  2. 選開發板與連接埠
  3. 上傳 Blink
  4. 改改看：燈閃多快
  5. 序列埠：讓板子說話
  6. 打開序列埠監控視窗
  7. 亂碼是怎麼來的
  8. 常見錯誤
這一課的目標：第一次「成功」：程式上傳成功、看到板子動、看到序列埠有字。之後每個感測器的數字，都是用序列埠送到電腦上看的。

1接上板子、打開範例

  1. 用 USB 線把 Arduino Uno 接上電腦。板子上的電源燈會亮。
  2. 打開 Arduino IDE。
  3. 選單 File → Open，開啟 範例程式\c03a-blink\c03a-blink.ino。
找不到檔案、或要開其他感測器的程式：看 開啟範例程式與安裝函式庫。
整塊板子都不亮：USB 線可能只能充電、不能傳資料。換一條線，或換一個 USB 孔。
這支程式在做什麼：讓板子內建的 L 燈（接在 D13）亮 1 秒、滅 1 秒，一直重複。setup() 只在開機時執行一次，loop() 會一直重複。

2選開發板與連接埠

程式要送到哪塊板子，要先告訴 IDE。點視窗上方的開發板選單（原本寫 Select Board）：

板子常見是 CH340 晶片的相容版，IDE 認不出來，所以要自己指定。按選單最下面的 Select other board and port…：

  1. 左邊搜尋框輸入 arduino uno，點 Arduino UNO（不是 UNO Mini 或 R4）。
  2. 右邊點寫著 Serial Port (USB) 的那一個（圖中是 COM4）。
  3. 兩邊都打勾後，按右下角的 OK。
你的埠號不一定是 COM4：每台電腦、每個 USB 孔都可能不同。判斷方法：括號寫 (USB) 的那一個；或把 USB 線拔掉再看，少掉的那一個就是 Arduino。
檢查點：視窗右下角出現 Arduino UNO on COM4（埠號以你的為準）。

3上傳 Blink

工具列左邊有兩顆圓形按鈕：

  • ✓（Verify）：只檢查程式能不能編譯，不送到板子。
  • →（Upload）：編譯並上傳到板子。這顆就是我們要按的。

按 →，下方 Output 區會先顯示編譯結果，接著上傳，約 10 秒。

右下角會跳出 Done uploading.，板子上的 L 燈開始每秒閃一次。

檢查點：L 燈閃爍。整塊板子上有好幾顆小燈，閃的那一顆旁邊印著 L。
上傳失敗？最常見是連接埠選錯，或序列埠監控視窗還開著（見最後的常見錯誤）。

4改改看：燈閃多快

程式裡有兩行 delay(1000);，意思是停一秒（1000 毫秒）。試試：

  1. 把兩個 delay(1000) 都改成 delay(200)，再按 → 上傳。燈會閃得多快？
  2. 把兩個數字改成不一樣（例如亮 1000、滅 200）。
程式沒有「結束」這回事：loop() 跑完會自動再跑一次，直到板子斷電。

5序列埠：讓板子說話

開啟 範例程式\c03b-serial-hello\c03b-serial-hello.ino，選好開發板與連接埠（同步驟 2），按 → 上傳。

這支程式用 Serial.println() 把文字從 USB 送到電腦：

Serial.begin(9600);                  // 開啟序列埠，速率 9600
Serial.println("你好，我是 Arduino");    // 送出一行文字
9600 是傳輸速率（鮑率），板子與監控視窗要設一樣，否則會看到亂碼。

6打開序列埠監控視窗

點 IDE 右上角的 Serial Monitor 圖示（像放大鏡的那顆，在最右邊）。也可以用選單 Tools → Serial Monitor。

如果還沒選開發板與連接埠，視窗會顯示黃色警告：

選好之後，板子說的話會一行一行出現：

檢查點：看到「你好，我是 Arduino」和一行一行跳出的「第 N 次」。
只有第一行沒看到？那一句只在板子開機時說一次。看不到的話，按板子上的 Reset 鈕重來一次，或先關掉監控視窗再重開。

8常見錯誤

狀況可能原因怎麼辦
選單裡看不到你的連接埠USB 線只能充電；CH340 驅動沒裝換一條 USB 線；重跑 install.cmd
上傳失敗，出現 port 相關錯誤連接埠選錯；序列埠監控視窗還開著；Node.js 雲端程式還在跑確認右下角寫的埠號；關掉 Serial Monitor；其他視窗的 Node.js 按 Ctrl + C
上傳成功但燈沒閃看錯燈（電源燈不會閃）；上傳的不是 Blink找印著 L 的那一顆；確認開的是 c03a-blink
監控視窗是亂碼速率不是 9600輸入框右邊的選單改成 9600 baud
監控視窗顯示 Not connected沒選開發板或連接埠回步驟 2
監控視窗什麼都沒有板子上跑的不是序列埠範例確認已上傳 c03b-serial-hello
永遠記得：要上傳新程式之前，先關掉序列埠監控視窗。一個連接埠同時只能有一個程式使用。
