ThingSpeak 看圖表與分享

資料送進頻道之後，怎麼看曲線、怎麼分享給別人、哪些情況看不到資料。

步驟
  1. 確認資料有送出去
  2. 到頻道看私人檢視
  3. 看 Field 1～5 的圖表
  4. 公開檢視與分享網址
  5. 看不到資料時
先準備好：已建立頻道並設定好 .env 的 Write API Key（見「ThingSpeak 註冊教學」與「雲端實作啟動教學」）。沒有板子也可以用 npm run mock 先練。

1確認資料有送出去

在 雲端實作 資料夾執行 npm start（或 npm run mock）。啟動摘要裡「ThingSpeak」那一行要是 ✔ 已啟用。接著每 15 秒左右，終端機會出現一行：

  ThingSpeak    ✔ 已啟用

[20:22:15] 收到第一筆資料，接下來每秒一筆：溫度 27.3°C、濕度 59.1%
[20:22:16] ThingSpeak 已收第 1 筆（溫度 27.3°C / 濕度 59.1%）
[20:22:31] ThingSpeak 已收第 2 筆（溫度 29.3°C / 濕度 53.7%）
[20:22:44] 狀態：ThingSpeak 成功 2 / 失敗 0　通知 （未啟用）
檢查點：看到「ThingSpeak 已收第 N 筆」，而且狀態行的失敗是 0。
為什麼是 15 秒一筆：ThingSpeak 免費版最短 15 秒才收一筆。儀表板每秒更新，但上傳雲端有內建節流（程式再多留 2 秒餘裕，實際約每 17 秒一筆），所以不是每秒都送。

2到頻道看私人檢視

瀏覽器登入 ThingSpeak，點選單 Channels → My Channels，點進你的頻道。預設停在 Private View（私人檢視，只有你看得到）。

  • Entries 每過 15 秒加 1：表示資料持續進來。
  • Last entry 寫「less than a minute ago」：表示剛剛還有收到。
Access 欄位：設成公開分享、重新載入頁面後，會顯示 Access: Public。

3看 Field 1～5 的圖表

頁面往下捲，每個 Field 各有一張折線圖，名稱是你在建頻道時填的：

圖表怎麼看
Field 1 溫度曲線跟著室溫慢慢變化
Field 2 濕度對 DHT11 呵氣，會看到濕度跳高再回落
Field 3 光線越暗數值越大；用手遮住會往上衝
Field 4 人體有人移動時出現 1，其餘是 0
Field 5 距離單位公分；量不到時是 -1
圖不會即時跳：每筆資料間隔 15 秒，要等下一個點出現。重新整理頁面或稍等一下，圖表會自己更新。

4公開檢視與分享網址

頻道設成「Share channel view with everyone」之後，點分頁 Public View，就是別人看到的畫面：

分享方法：複製瀏覽器網址列這串網址傳給對方，對方不用登入就能看到圖表。

分享的是「圖表網址」，不是 Key：不要把 Write API Key、.env 的內容、或 ntfy 主題名稱傳給別人。截圖前先遮起來。
為什麼別人不能亂寫資料：公開的只是「看圖表」的權限。要往頻道寫資料，一定要有 Write API Key。

5看不到資料時

狀況可能原因怎麼辦
啟動摘要顯示「ThingSpeak — 未設定（略過）」.env 的 THINGSPEAK_WRITE_KEY 是空的，或檔案沒存貼上 Write API Key，存檔後重新啟動
頻道 Entries 一直是 0Write Key 貼錯（貼成 Read Key）、多了空白，或還沒滿 15 秒重貼頻道 API Keys 頁最上面的 Write API Key；等 15 秒
終端機顯示失敗的次數一直增加Key 錯誤，或電腦連不上 ThingSpeak（網路被擋）確認網路；改練 npm run mock 的本機儀表板
圖表有線但某個 Field 沒有圖建頻道時該 Field 沒勾選頻道 Channel Settings 勾選並儲存
別人打開網址看不到頻道還是私人Sharing 分頁選「Share channel view with everyone」
想清掉練習用的假資料：Channel Settings 分頁下方有清空頻道資料（Clear Channel）的按鈕。
