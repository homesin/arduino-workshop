Email 通知教學

用 Gmail 的 SMTP 寄出警報信。免費，約 15 分鐘，不需要安裝 App。

步驟
  1. 先搞清楚：Email 通知適合什麼情況
  2. 開啟 Google 的兩步驟驗證
  3. 建立應用程式密碼
  4. 填進 .env
  5. 送一封測試信
  6. 常見問題

1先搞清楚：Email 通知適合什麼情況

程式會用 SMTP 把警報當成一封信，寄到你指定的信箱。人人都有信箱，不必安裝任何 App、不必加好友。

它不適合當唯一的通知管道：手機不一定即時跳通知（要看信箱 App 的收信頻率），而且程式自動寄出的信很容易被丟進垃圾郵件匣。比較適合當備援，主要通知仍建議用 Telegram、Discord、LINE 這類即時管道。
這份教學用 Gmail 示範。建議用一個測試用的 Gmail 帳號，不要用平常的主要信箱，因為「應用程式密碼」等於授權程式用這個信箱寄信。程式預設一天最多寄 50 封（EMAIL_DAILY_LIMIT），避免被當成垃圾信大量寄出。
用學校或公司信箱的話，要先問資訊中心 SMTP 主機名稱與埠號，設定方式相同。

2開啟 Google 的兩步驟驗證

Gmail 不能用登入密碼讓程式寄信，必須用「應用程式密碼」，而這個選項要先開啟兩步驟驗證才會出現。

開啟「兩步驟驗證」設定
  1. 用要寄信的 Google 帳號登入（Google 可能要你再驗證一次身分，請自己完成）。
  2. 依畫面啟用兩步驟驗證，通常要驗證一支手機。
怎麼知道有沒有開：如果直接去步驟 3 的網址，看到下面這個畫面，就是還沒開，回到這一步。

3建立應用程式密碼

開啟「應用程式密碼」
  1. 在「應用程式名稱」輸入 Arduino 通知（隨意取，用來辨識）。
  2. 按「建立」。
  3. Google 會顯示一組 16 碼密碼，通常每 4 碼一組、中間有空格，例如 abcd efgh ijkl mnop。只會顯示一次，先複製起來。
這組密碼等於能用你的信箱寄信：不要貼給任何人、不要放進截圖或公開網站。
不用了或外洩了，就回到同一頁，在清單裡按旁邊的刪除，舊密碼立刻失效。
填進 .env 時把中間的空格拿掉（abcdefghijklmnop），比較不會出錯。

4填進 .env

用 VS Code 開 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env）：

  1. 找到 NOTIFY_CHANNELS= 那一行，加上 email（用逗號分隔，可以同時開好幾種）：
    NOTIFY_CHANNELS=ntfy,email
    這行是「只送哪幾家」的過濾器，不加的話 Email 會被擋掉，什麼都收不到。
  2. 在下面加上這幾行（換成你自己的）：
    SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=你的Gmail地址
SMTP_PASS=16碼應用程式密碼（不含空格）
EMAIL_TO=收信的信箱
  3. 存檔。
等號兩邊不要有空格，也不要加引號。EMAIL_TO 可以填同一個信箱（寄給自己），也可以填別的信箱。SMTP_PORT 可以省略（預設就是 587），其他四個都要填，缺一個程式就當作還沒設定。

5送一封測試信

在 VS Code 終端機（路徑要在 雲端實作 資料夾裡）執行：

node test/send-test-alert.js email

只送給 Email，不影響其他管道。成功的話終端機會顯示：

Email 已送出：測試警報 · 校園環境監測站
✔ Email 送出成功

然後到收信的信箱找這封信，也要看一下垃圾郵件匣。信的內容是：

主旨：測試警報 · 校園環境監測站

測試警報 · 校園環境監測站
這是一則手動發出的測試訊息
時間 2026/11/12 20:30:07
檢查點：終端機顯示成功，而且信箱（收件匣或垃圾郵件匣）真的收到那封信，才算完成。
第一封被丟進垃圾郵件匣的話：把它標示為「不是垃圾郵件」，之後的警報信就比較會進收件匣。要實際看感測器觸發通知，接上 Arduino 後執行 npm start；沒有板子可用 npm run mock。

6常見問題

狀況原因與做法
找不到「應用程式密碼」，或顯示「您的帳戶無法使用這項設定」帳號沒開兩步驟驗證，回步驟 2。
終端機出現 EAUTH（認證失敗，Username and Password not accepted）最常見是用了登入密碼，要換成應用程式密碼；或 16 碼多了空格、貼錯；或密碼已被刪除。回步驟 3 重新建立。
終端機出現 ETIMEDOUT 或連線逾時網路擋掉 587 埠（學校網路常見）。先換手機熱點試試；仍不行可試 SMTP_PORT=465（SSL）。
程式說成功，但信箱沒看到信先看垃圾郵件匣；確認 EMAIL_TO 沒打錯；Gmail 有時要等幾十秒。
終端機說沒有任何通道被啟用NOTIFY_CHANNELS 沒加 email，或 SMTP_HOST、SMTP_USER、SMTP_PASS、EMAIL_TO 四個欄位沒填齊。
寄了很多封後突然寄不出去超過每日上限（預設 50 封，EMAIL_DAILY_LIMIT）；或被 Gmail 暫時限制，等一段時間再試。
Google 的設定畫面與規定可能調整，步驟以你實際看到的為準；官方說明見 應用程式密碼。
