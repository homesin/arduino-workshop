LINE 通知教學

用 LINE 官方帳號（Messaging API）接收 Arduino 的警報。免費額度每月 200 則，約 20 分鐘。

步驟
  1. 先搞清楚：LINE 通知怎麼運作
  2. 建立 LINE 官方帳號
  3. 在 Manager 啟用 Messaging API
  4. 到 LINE Developers 確認頻道
  5. 取得 Channel access token
  6. 把官方帳號加為好友
  7. 填進 .env
  8. 送一則測試通知
  9. 常見問題

1先搞清楚：LINE 通知怎麼運作

Arduino 偵測到東西，電腦的程式會透過 LINE 的 Messaging API，把訊息從你的官方帳號傳給加了這個官方帳號好友的人。所以要準備的是：一個官方帳號、一組 Token，還有你自己加它為好友。

LINE Notify 已經停止服務（2025 年 3 月 31 日結束）。網路上舊的「LINE Notify 教學」都不能用，這份教學用的是官方帳號的 Messaging API，是不同的東西。
申請流程也改過：2024 年 9 月 4 日起，不能再直接在 LINE Developers Console 建立 Messaging API 頻道。現在要先建立 LINE 官方帳號，再啟用 Messaging API（步驟 2、3）。舊教學寫的「到 developers.line.biz 建立頻道」已不適用。
額度：官方帳號的「輕用量」方案月費 0 元、每月 200 則免費、不能加購（2026 年 11 月 1 日價格調整後維持不變，2026-11 查證，之後可能再變）。程式用「群發」，加你好友的人越多，每則扣越多；程式預設一天最多送 20 則，避免額度被用光。

2建立 LINE 官方帳號

開啟 LINE Official Account Manager 註冊 LINE Business ID
  1. 登入 LINE Business ID：用 LINE 帳號或 email 登入（沒有就先註冊）。登入畫面可能要驗證碼，請自己輸入。
  2. 進到 Official Account Manager，左側選單點「建立」，會開啟「建立 LINE 官方帳號」表單。
  3. 依表單填寫帳號名稱、業種等資訊，確認後送出。個人練習用的話，名稱可以取例如「Arduino 通知測試」。
表單的欄位和審核規定可能隨 LINE 調整，以畫面為準。方案選「輕用量」（免費）即可。

3在 Manager 啟用 Messaging API

  1. 進入你的官方帳號，右上角「設定」→ 左側「Messaging API」。
  2. 還沒啟用的話，這一頁會有「啟用 Messaging API」按鈕，按下去。
  3. 系統會請你選一個 Provider（開發者的分類，名稱隨意，例如 Arduino Workshop）。Provider 建好後不能更改或刪除，取名前想一下。
  4. 完成後，這一頁的「狀態」會顯示使用中，並出現 Channel ID 與 Channel secret。
這個程式只需要 Token，用不到 Channel secret 和 Webhook 網址，Webhook 欄位留空就好。

4到 LINE Developers 確認頻道

開啟 LINE Developers Console
  1. 用同一組 LINE Business ID 登入。
  2. 左側選你剛才的 Provider，會看到一個 Messaging API 類型的頻道（名稱和官方帳號相同）。點進去。
  3. 切到「Messaging API」分頁。
如果找不到頻道，確認你登入的是建立官方帳號的那一組 LINE Business ID，而且在 Provider 裡有 Admin 權限。

5取得 Channel access token

在 Messaging API 分頁最下面，「Channel access token (long-lived)」。第一次會是一顆 Issue 按鈕，按下去就會產生一長串 Token，按旁邊的複製圖示複製。

Token 等於機器人的密碼：不要貼在群組、截圖、簡報或公開網站。
已經有 Token 的人，不要按 Reissue。重新發行會讓舊 Token 立刻失效，原本在用它的程式就送不出去了。

6把官方帳號加為好友

官方帳號只能傳訊息給加了它好友的人，沒加好友就收不到。

  1. 在 Messaging API 分頁往下捲，找到 QR Code。
  2. 用手機 LINE 掃描（LINE 的「加好友」→「行動條碼」），按「加入」。
好友人數可以在 Manager 上方帳號名稱旁看到。一起收通知的人，都要各自掃碼加好友。

7填進 .env

用 VS Code 開 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env）：

  1. 找到 NOTIFY_CHANNELS= 那一行，加上 line（用逗號分隔，可以同時開好幾種）：
    NOTIFY_CHANNELS=ntfy,line
    這行是「只送哪幾家」的過濾器，不加的話 LINE 會被擋掉，什麼都收不到。
  2. 在下面加一行，貼上剛才複製的 Token：
    LINE_CHANNEL_ACCESS_TOKEN=貼上你的Token
  3. 存檔。
等號兩邊不要有空格，也不要加引號。Token 很長（約 170 個字元），是正常的。

8送一則測試通知

在 VS Code 終端機（路徑要在 雲端實作 資料夾裡）執行：

node test/send-test-alert.js line

只送給 LINE，不影響其他管道。成功的話終端機會顯示：

LINE 已送出：測試警報 · 校園環境監測站
✔ LINE 送出成功

同時手機 LINE 裡，你的官方帳號會傳來一則「測試警報」。

檢查點：終端機顯示成功，而且手機 LINE 真的收到那則訊息，才算完成。
要實際看感測器觸發通知：接上 Arduino 後執行 npm start；沒有板子可用 npm run mock。測試也會消耗額度，一次一則而已。

9常見問題

狀況原因與做法
錯誤 401（Authentication failed）Token 貼錯、多了空格，或已被 Reissue 讓舊 Token 失效。回步驟 5 重新複製。
程式說成功，手機沒收到最常見是沒有加官方帳號好友（步驟 6），或加的是別的官方帳號。
終端機出現「LINE 預演」程式在說「沒有設定 LINE，所以只印出來、沒有真的送」。檢查 LINE_CHANNEL_ACCESS_TOKEN 有沒有填，以及 NOTIFY_CHANNELS 有沒有 line。
終端機說沒有任何通道被啟用NOTIFY_CHANNELS 沒加 line，或 Token 沒填。
送出 429 或訊息突然沒了本月 200 則免費額度用完。到 Manager 看用量；程式預設每天最多 20 則，可在 .env 用 LINE_DAILY_LIMIT 調整。
找不到「啟用 Messaging API」可能已經啟用了（狀態顯示「使用中」就是）；或你不是這個官方帳號的管理員。
在 Developers Console 找不到「建立頻道」正常，2024 年 9 月起已經移除。要從 Official Account Manager 建官方帳號再啟用 Messaging API（步驟 2、3）。
LINE 的畫面、方案與規定常有調整，步驟以你實際看到的為準；官方說明見 Messaging API 入門。
