一鍵安裝與驗收

貼一行指令，把上課要用的軟體全部裝好，最後看結果表是不是全綠勾。約 5～15 分鐘，視網路而定。

步驟
  1. 先確認條件
  2. 開啟 PowerShell 並貼上指令
  3. 安裝過程在做什麼
  4. 看結果表驗收
  5. 結果不是全綠怎麼辦
  6. 插上板子再驗收一次
裝了什麼：Arduino IDE（寫程式、上傳）、Uno 板子核心、DHT11 用的函式庫、CH340 驅動（讓電腦認得相容板）、VS Code、Node.js（後半段把資料送上雲端）、雲端專案的套件，以及教材。

1先確認條件

  • 電腦連得上網路（要下載軟體）。
  • 你的帳號有安裝軟體的權限。公務電腦若被管制，請先問資訊人員。
  • Arduino 板子先不用接也可以。接上的話，最後會多一項上傳測試。

2開啟 PowerShell 並貼上指令

  1. 按鍵盤的 Win 鍵，輸入 PowerShell，按 Enter 開啟。
  2. 貼上下面這一行，按 Enter：
irm https://homesin.github.io/arduino-workshop/get.ps1 | iex
  1. 安裝過程中如果跳出確認視窗（要求系統管理員權限），一律按「是」。
貼上的方法：在 PowerShell 視窗裡按滑鼠右鍵就會貼上；也可以按 Ctrl + V。
教材已經在電腦上的話：也可以直接雙擊教材資料夾裡 安裝程式\install.cmd，效果一樣。

3安裝過程在做什麼

安裝程式會一項一項處理，每一段以 ▶ 開頭。已經裝過的會直接顯示「已安裝，跳過」，所以重複執行沒有副作用。

段落項目用來做什麼
1Arduino IDE寫程式與上傳到板子
2Uno 板子核心 arduino:avr讓 IDE 知道怎麼編譯給 Uno
3函式庫 SimpleDHT讀 DHT11 溫濕度（本次唯一需要的函式庫）
4CH340 驅動相容板的 USB 晶片驅動；沒裝的話插上板子也不會出現連接埠
5VS Code 與中文語言套件選用的編輯器
6Node.js 20 版以上雲端實作用
7雲端專案套件執行 npm install
8Codex CLI上課卡關時問 AI 助教用（選用）
9～10驗收：編譯、雲端程式自我測試不需要板子，也不會真的發通知
11～12檢查板子、燒錄 Blink有插板子才會做
要等多久：第一次安裝會下載 Arduino IDE、板子核心（約 100 MB）等，網路慢的話板子核心那一段要好幾分鐘，停在那裡是正常的，不要關視窗。

5結果不是全綠怎麼辦

看到什麼意思與處理
偵測到板子 ！（沒有插板子，或 USB 線只能充電）先插上板子，再重新執行一次指令即可。換一條 USB 線試試
偵測到板子 ✗（板子有插但缺 CH340 驅動）看上方「CH340 驅動」那一列的說明，裝好後重新插拔
CH340 驅動 ！原廠 Uno 不需要；相容板的話，到 WCH 官網下載 CH341SER.EXE 手動安裝
燒錄測試 ✗換一條 USB 線或換 USB 孔；重新插拔後再執行一次
Codex 登入 ！第一次使用才需要，之後再登入，不影響上課
.env 設定檔 ！已替你從範本複製；金鑰要自己填（見雲端實作教學）
Node.js 安裝後找不到 node關掉視窗，重新開一個再跑一次（環境變數要重開才生效）
winget 自動安裝失敗後面的軟體都靠它，請找講師
重新執行不會重裝：修好之後再貼一次同一行指令，已完成的項目會自動跳過。

6插上板子再驗收一次

沒插板子時，最後會顯示「偵測到板子 ！」。插上 Arduino（USB 線要能傳資料），再貼一次指令，會多這幾項：

  • 偵測到板子 ✓，說明欄寫連接埠，例如 COM4。
  • 燒錄測試 ✓：腳本實際把 Blink 上傳到板子。
用眼睛確認：看板子上印著 L 的小燈，每秒閃一下就正常。腳本只能確認「上傳成功」，燈有沒有閃要你自己看。
注意：這一步會把板子上原有的程式換成 Blink。之後要跑感測器範例，再重新上傳對應的程式即可。
