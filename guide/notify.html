其他通知管道：LINE、Discord、Telegram、Slack、Email

課堂上用 ntfy，課後想換別的，程式都已寫好，只差憑證與設定。

內容
  1. 先看總覽：每種管道要準備什麼
  2. 選一個，照它的教學做
  3. 可以同時開好幾種

1先看總覽：每種管道要準備什麼

管道要準備什麼.env 要填注意
ntfy（課堂用）自訂主題名稱，不用註冊NTFY_TOPIC主題名稱像密碼，別外流
LINE官方帳號＋Messaging API 頻道LINE_CHANNEL_ACCESS_TOKEN每月 200 則免費；群發給 N 位好友扣 N 則
Discord頻道的 Webhook 網址DISCORD_WEBHOOK_URL校園網路可能封鎖 Discord，先實測
TelegramBotFather 建的機器人＋你的 Chat IDTELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID		要先對機器人說一句話
SlackIncoming Webhook 網址SLACK_WEBHOOK_URL需要有 Slack 工作區
EmailSMTP 主機與信箱密碼SMTP_HOST、SMTP_USER、SMTP_PASS、EMAIL_TO不即時，容易進垃圾信
LINE Notify 已停止：它在 2025 年 3 月 31 日結束服務，網路上舊的「LINE Notify 教學」都不能用。現在要用 LINE，走官方帳號的 Messaging API（見下方 LINE 通知教學）。
這些管道程式都已經寫好（在 雲端實作\src\channels）。你只要做兩件事：把憑證填進 .env，再把管道名稱加進 NOTIFY_CHANNELS。

2選一個，照它的教學做

每個管道都有從頭到尾的圖文教學，設定內容與注意事項都在裡面，這頁不重複。

想用適合誰完整教學
LINE每天都在用 LINE、想直接收在手機上；要自己申請，約 15 分鐘LINE 通知教學
Discord最省事，不用開發者帳號；已實測可行Discord 通知教學
Telegram免費、幾乎沒有額度限制；已實測可行Telegram 通知教學
Slack學校或團隊本來就在用 Slack；已實測可行Slack 通知教學
Email不必裝 App，適合當備援，不適合當唯一管道；已實測可行Email 通知教學

3可以同時開好幾種

.env 的 NOTIFY_CHANNELS 用逗號分隔，例如 ntfy,line,email，名稱不分大小寫。每份教學最後都有 npm run mock 測試步驟。

預演模式會真的送：只要 .env 裡有憑證，npm run mock 就會真的送出通知。測試前確認收件的是你自己。
