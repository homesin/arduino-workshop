開啟範例程式與安裝函式庫

每個感測器都是一支範例程式：怎麼找到它、開起來、上傳，缺函式庫時怎麼補。

步驟
  1. 範例放在哪裡
  2. 用 File → Open 開啟
  3. 換下一支程式的固定流程
  4. 安裝函式庫（SimpleDHT）
  5. 七支範例對照表
  6. 常見錯誤
提醒：開檔本身不需要接板子；要上傳時，才需要選好開發板（Arduino UNO）與連接埠。還沒選過，請看 Arduino 第一次上傳與序列埠。

1範例放在哪裡

一鍵安裝完成後，教材在桌面的 arduino-workshop 資料夾，範例程式都在裡面的 範例程式：

桌面\arduino-workshop\範例程式\c04a-dht11\c04a-dht11.ino

每支程式一個資料夾，裡面一個同名的 .ino 檔。Arduino 規定資料夾名稱要和 .ino 檔名一樣，所以不要自己改名、也不要把 .ino 檔拖出來。

2用 File → Open 開啟

  1. 在 Arduino IDE 按 File → Open（快速鍵 Ctrl + O）。
  2. 在跳出的視窗裡，走到 桌面 → arduino-workshop → 範例程式 → c04a-dht11。
  3. 點 c04a-dht11.ino，按右下角的開啟。

程式會開在一個新分頁（或新視窗），標題列會寫程式名稱。選單是英文，但「開啟」視窗是你電腦的語言。

檢查點：視窗標題變成 c04a-dht11 | Arduino IDE，右下角仍然是 Arduino UNO on COM…。

3換下一支程式的固定流程

  1. 關掉序列埠監控視窗（點它分頁上的 ✕）。開著的話，上傳會因為連接埠被占用而失敗。
  2. File → Open 開啟下一支程式。
  3. 按左上角 →（Upload），或按 Ctrl + U。
  4. 等右下角出現 Done uploading.。
  5. 需要看數字時，再按 Ctrl + Shift + M 開序列埠監控視窗，速率選 9600 baud。
每次上傳都會蓋掉板子上原本的程式：板子同一時間只跑一支程式，最後上傳的那支。

4安裝函式庫（SimpleDHT）

只有 DHT11 的程式（c04a 和 c05）需要 SimpleDHT 函式庫。一鍵安裝已經幫你裝好；如果編譯時說找不到，照下面手動裝：

  1. 按左邊的書本圖示（Library Manager），或 Ctrl + Shift + I。
  2. 搜尋框輸入 SimpleDHT。
  3. 找作者是 Winlin 的那一個，按 INSTALL。裝好後會顯示 installed。
不要裝錯：名稱很像的有 DHT sensor library、SimpleDHT 的其他版本。範例是為 SimpleDHT（Winlin）寫的。

5七支範例對照表

資料夾做什麼接線
c03a-blink內建 L 燈閃爍不用接線
c03b-serial-hello序列埠印字不用接線
c04a-dht11溫度、濕度DATA → D2
c04b-hcsr04超音波距離Trig → D4、Echo → D5
c04c-pir有沒有人OUT → D3
c04d-ldr亮或暗AO → A1
c05-sensor-node四個一起讀、送雲端沿用上面四個，不用重接

感測器的 VCC／GND 都接麵包板的紅軌／藍軌，細節看 麵包板與四感測器接線。

6常見錯誤

看到什麼原因怎麼辦
fatal error: SimpleDHT.h: No such file沒裝 SimpleDHT照步驟 4 安裝，再按上傳
unable to open port COM…序列埠監控視窗還開著，或連接埠選錯關掉監控視窗；右上角確認連接埠
IDE 問「要建立資料夾嗎」.ino 檔被拖出資料夾、或改過名字直接開資料夾裡的原檔，不要改名
上傳成功，但序列埠是亂碼速率不是 9600監控視窗右上方選 9600 baud
上傳成功，但數字不對接線、或上傳了別支程式看標題列的程式名稱，再對照步驟 5 的接線
