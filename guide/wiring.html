麵包板與四感測器接線

認識麵包板，把 DHT11、HC-SR04、HC-SR501、LM393 光敏模組接到 Uno。

步驟
  1. 準備零件
  2. 麵包板怎麼讀
  3. 杜邦線三種用法
  4. 先接電源
  5. 接訊號線
  6. 逐個驗證
  7. 四個一起讀
  8. 常見錯誤
接線的鐵則：先拔掉 USB 再接線，接完、檢查過紅藍沒有接反，才插 USB。5V 與 GND 接反可能燒壞模組。

1準備零件

零件數量備註
Arduino Uno（相容板）1USB 線一條，要能傳資料
400 孔迷你麵包板1當作電源分配板
DHT11 溫濕度模組1
HC-SR04 超音波模組1
HC-SR501 人體紅外線模組1
LM393 光敏模組1
杜邦線若干母對公為主，另需公對公 2 條（Uno 到麵包板）
沒有 LED、電阻、蜂鳴器：本次只有感測器，輸出是「螢幕上的數字」和「手機通知」。

2麵包板怎麼讀

麵包板內部有金屬片把孔連在一起，看不見，但一定要懂。重點三件事：

  1. 同一欄、同一半的 5 個孔相通（橘色框）：插在同一欄的兩根線，等於接在一起。
  2. 中央溝槽兩邊不通：溝槽上下是兩組獨立的孔。
  3. 兩側電源軌整條相通：紅線那條接 5V、藍線那條接 GND，所有模組從這裡取電。
迷你麵包板的電源軌，有些在中間是斷開的：如果軌道中間有缺口，左右兩半不通。接完先量一下（或看紅藍線有沒有缺口）；本課程接的四個模組盡量都插在同一半。這一點我們還沒用你手上的那塊實測。

3杜邦線三種用法

種類兩端用在哪
公對公兩端都是針Uno 的 5V、GND 接到麵包板電源軌
母對公一端孔、一端針最常用：母端插感測器的針腳，公端插 Uno 或麵包板
母對母兩端都是孔本次幾乎用不到
感測器上的針腳是公針：所以用母對公杜邦線，母端插感測器，公端插 Uno 或麵包板。

4先接電源

Uno 只有一個 5V 孔，但四個模組都要 5V，所以用麵包板電源軌分出去。Uno 只拉兩條線：

  • Uno GND → 麵包板藍色（－）電源軌（公對公）
  • Uno 5V → 麵包板紅色（＋）電源軌（公對公）
夠不夠電：四個合計約 90 mA，遠低於 USB 的約 500 mA，不需要外接電源。（這是典型值估算，不是實測。）
順序：先接 GND 軌，最後才接 5V 軌；插電前確認紅藍沒有接反。

5接訊號線

每個模組的 VCC 接紅軌、GND 接藍軌，再把訊號腳接到 Uno 指定的腳位：

模組VCCGND訊號腳接到 Uno
DHT11 溫濕度紅軌（5V）藍軌（GND）DATAD2
HC-SR501 人體紅外線紅軌藍軌OUTD3
HC-SR04 超音波紅軌藍軌TrigD4
EchoD5
LM393 光敏模組紅軌藍軌AOA1
D0、D1 不要接任何東西：它們是序列埠，接了會無法上傳程式。
LM393 的 DO 不接：光敏模組的針腳順序是 AO、DO、GND、VCC。本次用 AO 讀數值，DO（只有亮／暗兩種狀態）空接。
每個模組的針腳順序不一定相同：以模組板子上印的字（VCC、GND、OUT、DATA…）為準，不要只憑位置猜。

6逐個驗證

全部接完，檢查紅藍沒有接反，再插上 USB。建議一個一個測，出問題比較好找。用 Arduino IDE 開啟並上傳，開序列埠監控視窗（速率 9600）：

程式（範例程式\）測哪個動手試看到什麼
c04a-dht11溫濕度對著感測器呵氣濕度數字上升再慢慢回落
c04b-hcsr04超音波手放探頭前 10–30 公分，前後移動距離數字跟著變
c04c-pir人體紅外線在感測器前揮手0 變 1，幾秒後自己變回 0
c04d-ldr光敏用手遮住感測器數值變大（越暗越大）
DHT11 需要函式庫：安裝程式已裝好 SimpleDHT。其他三個不需要函式庫。

7四個一起讀

單獨都正常之後，上傳 c05-sensor-node（接線完全相同，不用重接）。序列埠監控視窗每秒會出現一行：

{"t":26,"h":58,"pir":0,"dist":23,"light":280}
欄位意思
t溫度（°C）
h濕度（%）
pir人體紅外線：0 沒人，1 有人
dist距離（公分），量不到是 -1
light光敏讀值，越暗越大
檢查點：手遮光敏、手揮人體紅外線、手靠近超音波、對 DHT11 呵氣，四個欄位都要跟著變。

8常見錯誤

狀況可能原因怎麼辦
溫濕度一直是 0 或讀取失敗DATA 沒接在 D2；讀太快對照接線；程式間隔不要小於 1 秒
距離一直是 -1沒收到回波先查 VCC 與 Trig（D4）、Echo（D5）有沒有接反；前方太空曠超出量程也會 -1
人體紅外線讀值亂跳剛插電還在暖機等約一分鐘；HIGH 會維持好幾秒，不是每次揮手都變一次
光敏數字和直覺相反它是越暗越大正常現象，不是壞掉
某個欄位一直不變該模組線沒接好拔掉其他模組逐一排除，回到單獨測
幾個模組都沒反應電源軌左右兩半不通；5V 與 GND 接反檢查軌道中間有沒有缺口；紅藍線對調要立刻拔 USB
上傳失敗D0 或 D1 接了線；序列埠監控視窗還開著拔掉 D0、D1 的線；關掉監控視窗
門檻要現場量：光敏的「天暗」門檻、超音波的「靠近」距離等數字，都只是範例，以你現場讀到的為準。
