Discord 通知教學

從註冊帳號、建立伺服器，到讓 Arduino 的警報傳到 Discord 頻道。免費、不用手機號碼，約 10 分鐘。

步驟
  1. 註冊並登入 Discord
  2. 建立一個專用的測試伺服器
  3. 開啟頻道設定
  4. 整合 → Webhook → 建立 Webhook
  5. 複製 Webhook 網址
  6. 填進 .env
  7. 送一則測試通知
  8. 常見問題

1註冊並登入 Discord

Discord 是免費的聊天軟體。只要 email 就能註冊，不需要手機號碼。網頁版和手機 App 擇一即可：

註冊 Discord 登入（有帳號）
  1. 註冊：填 email、顯示名稱、使用者名稱、密碼、生日，可能要通過「我不是機器人」驗證。
  2. 驗證 email：到信箱點 Discord 寄來的確認信，否則部分功能會被限制。
  3. 手機已登入、想在電腦登入：登入頁右邊有 QR Code。手機 Discord App 點右下角頭像，找「掃描 QR Code」，對準螢幕掃，按確認即可，不用輸入密碼。

2建立一個專用的測試伺服器

建議另開一個只有自己的小伺服器來收通知，不要用現有的伺服器，以免警報訊息被別人看到。

  1. 左側欄最下面的 ＋（新增伺服器），選「建立自己的」。
  2. 問「多介紹一下您的伺服器」時，選「我和我的好友」。
  3. 取個名字，例如 Arduino 通知測試，按「建立」。

建好後會進到預設的文字頻道 #一般，通知就會送到這裡。

3開啟頻道設定

在左側頻道清單，把滑鼠移到 #一般 上，右邊會出現一個齒輪（編輯頻道），點它。

看不到齒輪的話，要確認你是這個伺服器的擁有者；自己建的伺服器一定有。

4整合 → Webhook → 建立 Webhook

  1. 在頻道設定左側選單，點「整合」。
  2. 進到 Webhook 清單，如果顯示「您沒有 Webhook！」，再按一次中間的「建立 Webhook」。

5複製 Webhook 網址

建好後會出現一個預設叫 Spidey Bot 的 Webhook，貼文頻道是 #一般。名稱和頭像可以改，之後通知會用這個名字顯示。

按「複製 Webhook 網址」，出現「已複製！」就成功了，網址已經在剪貼簿裡。

Webhook 網址等於密碼：知道的人都能往你的頻道發訊息。不要貼在聊天群組、截圖、簡報或公開網站。
外洩了就在同一頁按「刪除 Webhook」，再重建一個，舊網址立刻失效。

6填進 .env

用 VS Code 開 桌面\arduino-workshop\雲端實作\.env（Explorer 裡 雲端實作 → .env）：

  1. 找到 NOTIFY_CHANNELS= 那一行，加上 discord（用逗號分隔，可以同時開好幾種）：
    NOTIFY_CHANNELS=ntfy,discord
    這行是「只送哪幾家」的過濾器，不加的話 Discord 會被擋掉，什麼都收不到。
  2. 在下面加一行，貼上剛才複製的網址：
    DISCORD_WEBHOOK_URL=貼上網址
  3. 存檔。
等號兩邊不要有空格，也不要加引號。網址會很長，是正常的。

7送一則測試通知

在 VS Code 終端機（路徑要在 雲端實作 資料夾裡）執行：

node test/send-test-alert.js discord

只送給 Discord，不影響其他管道。成功的話終端機會顯示：

Discord 已送出：測試警報 · 校園環境監測站
✔ Discord 送出成功

同時 Discord 的 #一般 頻道（網頁、手機都看得到）會多一則訊息：

檢查點：終端機顯示成功，而且頻道裡真的出現那則訊息，才算完成。
要在手機跳通知：手機 Discord App 要允許通知，並確認這個伺服器的通知設為「所有訊息」。要看感測器真的觸發警報，接上 Arduino 後執行 npm start；沒有板子可用 npm run mock。

8常見問題

狀況原因與做法
錯誤 404（Unknown Webhook）網址貼錯、少貼一段，或那個 Webhook 已被刪除。回步驟 5 重新複製。
錯誤 429送太快（同一個 Webhook 每分鐘有上限）。程式有冷卻時間，一般不會碰到；等一分鐘再試。
終端機說沒有任何通道被啟用NOTIFY_CHANNELS 沒加 discord，或 DISCORD_WEBHOOK_URL 沒填。
程式說成功，但沒看到訊息確認看的是建 Webhook 的那個頻道（網址綁定頻道）；有沒有切到別的伺服器。
找不到頻道旁的齒輪要把滑鼠移到頻道名稱上才會出現；或對頻道按右鍵選「編輯頻道」。
校園網路連不上學校網路可能擋 Discord。先換手機熱點試試，確認是不是網路的問題。
Discord 的畫面和選單名稱可能改版，步驟以你實際看到的為準。
