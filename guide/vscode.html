用 VS Code 開專案、開終端機、問 AI 助教

VS Code 是這堂課的「工作桌面」：開教材資料夾、改設定檔、跑指令、問 AI。上傳程式主線仍用 Arduino IDE。

步驟
  1. 開啟教材資料夾
  2. 用 VS Code 改 .env 設定檔
  3. 內建終端機
  4. 選修：一鍵編譯並上傳
  5. AI 助教 Codex：卡關時問它
  6. 常見問題
什麼時候用 VS Code：第一～四章寫程式、上傳、看序列埠，用 Arduino IDE。 第五、六章要改設定檔、跑 npm 指令，這時用 VS Code，不用另外開記事本和 PowerShell。

1開啟教材資料夾

  1. 桌面的 arduino-workshop 資料夾裡有 Visual Studio Code 捷徑，點兩下開啟。
  2. 選單 File → Open Folder…，選桌面的 arduino-workshop 資料夾，按選擇資料夾。
  3. 跳出 Do you trust the authors of the files in this folder?，按 Yes, I trust the authors。
一定要按 Yes：選 No 會進入 Restricted Mode（受限模式），一鍵上傳等功能會被停用。

左邊 Explorer 會列出整個教材：範例程式、雲端實作、學員講義.html、AGENTS.md。

第一次開會遇到的干擾，都可以忽略：
  • 中間的 Get started with VS Code 歡迎頁（有 Set up Copilot 按鈕）：直接關掉那個分頁。
  • 右下角「是否安裝 C/C++ Extension Pack」：不用裝，按 ✕ 關掉。
  • 右下角其他跳出的提示（更新、快捷鍵說明…）：按 ✕ 關掉，不影響上課。
選單是英文：VS Code 預設英文介面，這份教學用英文選單名稱。想換中文可以裝 Chinese (Traditional) Language Pack，不裝也不影響上課。

2用 VS Code 改 .env 設定檔

第六章要把序列埠、ThingSpeak 和 ntfy 的設定填進 雲端實作\.env。這個檔案要由範本複製出來：

  1. Explorer 展開 雲端實作，點 .env.example，看到範本內容（圖中上方）。
  2. 在終端機（步驟 3）進到 雲端實作，輸入 copy .env.example .env，按 Enter。
  3. Explorer 點 .env，把 SERIAL_PORT=COM3 改成你的 COM 編號，按 Ctrl + S 存檔。
copy 只做一次：在 PowerShell 裡 copy .env.example .env 如果 .env 已經存在，會直接覆蓋、不會問你，之前填的金鑰全部消失。已經有 .env 就直接改它。
.env 等於密碼：ThingSpeak 的 Write API Key 和 ntfy 主題名稱不要截圖、不要貼到群組、不要貼給 AI。
檢查點：檔案分頁標題的檔名右邊沒有白點（有白點代表還沒存檔）。

3內建終端機

  1. 開終端機：按 Ctrl + `（反引號，在 Tab 鍵上方），或選單 Terminal → New Terminal。
  2. 視窗下方出現終端機，提示字元會顯示目前所在的資料夾，例如 PS D:\SYSTEM\Desktop\arduino-workshop>。
  3. 要進到雲端實作：輸入 cd 雲端實作，按 Enter。提示字元會變成 …\arduino-workshop\雲端實作>。
  4. 之後的指令都在這裡打：npm run ports、npm run mock、npm start。
想做什麼怎麼做
停掉正在跑的程式（npm start、npm run mock）點終端機，按 Ctrl + C
多開一個終端機終端機右上角的 ＋；右邊清單切換
關掉一個終端機清單裡選它，按右上角的垃圾桶
放大終端機面板右上角的放大圖示（再按一次還原）
要上傳 Arduino 程式前：先在終端機按 Ctrl + C 停掉 Node.js，並關掉 Arduino IDE 的序列埠監控視窗。一個連接埠同時只能一個程式使用。
剛裝好的 npm 或 node 找不到：把 VS Code 整個關掉再重開，終端機才會認得新安裝的指令。

4選修：一鍵編譯並上傳

教材已經設好工作（Task），可以不開 Arduino IDE，直接在 VS Code 上傳：

  1. 按 Ctrl + P，輸入 c04a-dht11.ino，按 Enter 打開程式。
  2. 按 Ctrl + Shift + B。
  3. 下方終端機顯示編譯結果，最後出現綠色的 ✓ 上傳完成。

其他工作：選單 Terminal → Run Task…，可以選 Arduino: 只編譯、Arduino: 序列埠監控、Arduino: 列出連接埠。

目前開哪支就上傳哪支：上傳前看一下分頁標題是不是你要的程式。
沒反應或失敗：① 資料夾沒按「信任」（步驟 1）；② 前面沒有打開 .ino 檔；③ 序列埠監控視窗或 npm start 還開著。

5AI 助教 Codex：卡關時問它

安裝程式已經裝好 Codex（OpenAI 的終端機 AI 助教）。它會讀教材資料夾裡的 AGENTS.md，知道這堂課在做什麼、腳位怎麼接。

  1. 在 VS Code 開終端機，確認在 arduino-workshop 這一層（不是 雲端實作）。
  2. 輸入 codex，按 Enter。第一次使用會要求登入，照畫面用 ChatGPT 帳號登入。
  3. 看到下面的畫面，在底部的輸入框用中文描述問題，按 Enter。

怎麼問，它才幫得上忙：

  • 說清楚做到第幾章、接了哪些腳位、看到什麼現象。例如：「第四章 DHT11，序列埠一直顯示讀取失敗，我接 DATA 到 D2。」
  • 有錯誤訊息就整段複製貼上。
  • 它建議改檔案時，會先問你；看清楚要改什麼，再回答同意。
  • 它會一步一步帶你，不會一次丟一大串，做完一步再回報結果。
不要貼給 AI 的東西：.env 裡的 Write API Key、ntfy 主題名稱。要檢查設定，只告訴它「有填」或「沒填」。
離開：按 Ctrl + C 兩次。之後要再問就再輸入 codex。
它是輔助，不是標準答案：它說的和講義不一樣時，以講義為準，並問老師或助教。上課現場先問身邊的助教最快。
